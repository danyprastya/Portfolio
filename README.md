# Dany Prastya — Portfolio

Personal portfolio showcasing custom web applications and business automation workflows. Built to load fast, look clean, and demonstrate real-world project outcomes.

## Services Showcased

- **Web Development**: Responsive, high-performance web apps built with Next.js & Tailwind CSS.
- **AI Automation**: Workflow integrations (n8n, API connections) to eliminate repetitive tasks.
- **Maintenance & Support**: App optimization, bug patches, and feature upgrades.

## Stack & Performance

- **Framework**: Next.js 15 (App Router) + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: `motion/react` (lightweight framer-motion successor)
- **Asset Optimization**: 90%+ image compression via WebP format
